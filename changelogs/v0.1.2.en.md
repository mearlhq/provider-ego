### Startup and recovery

- On macOS, check Ego's standard per-user installation outside PATH so desktop hosts can locate `ego-browser`.
- On Windows, launch native `ego-browser.exe` directly, checking PATH followed by `.local\share\ego\active_version_dir` under the user home directory. No shell wrapper is required.
- Failed startup before the handshake allows a subsequent request after installation, without restarting the Provider. Dispatched requests are never automatically replayed after connection loss or timeout.

Real macOS validation covers connection, page operations, device emulation and task control. Windows path resolution has automated coverage but real-device validation is still pending. Linux is not yet an officially supported Ego Lite platform.

Requires Mearl 3.0.7+ and Node.js 22.23.4+. After upgrading Mearl, restart both browser hosts and the independent Provider control host to avoid retaining an older protocol implementation.
