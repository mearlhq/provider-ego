### Device shell

- Update the bundled Native Host to fix root WebView timeouts when enabling App simulation and the device shell on a new tab.
- Blank pages prepare the simulation before the first top-level navigation. Once an HTTP document loads, business operations continue through the root WebView. The first request retains the App user agent and device configuration.
- Preserve reload behavior when switching the shell on existing HTTP pages. A missing root WebView still produces an explicit error.

Validated App home-page loading with the device shell, user agent, JSBridge and mobile viewport in Ego on macOS. The regular Chrome extension path was also checked for opening, reloading and toggling the shell. Windows real-device validation remains pending.
