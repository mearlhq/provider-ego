### First stable release

- Manage task Spaces, page operations, handoff, resume and completion through Ego's native channel, without a browser extension or separate cooperation Skill.
- Device and App emulation, device shells, root WebViews and installed App host services. Real authorization still requires user approval.
- Default extension Agent access off in macOS EgoLite while respecting explicit user overrides. Idle pages do not poll control ownership.
- Release page hosts when their pages close without affecting retained result pages.

Requires Mearl 3.0.6+, Node.js 22.23.4+ and `ego-browser` on PATH.

```bash
npx @mearl/setup@latest provider install @mearl/provider-ego
```
