### 浏览器发现与任务会话

- 启动 Ego Lite 后，Mearl 3.2 可以通过 `browser_list` 发现浏览器。用 `session_manage new` 创建 Space，或传入 `providerOptions.spaceId` 关联已有 Agent Space。
- 页面操作、接管、恢复和结束复用同一个会话 ID。接入同一任务页的 Mearl 扩展优先处理它支持的页面操作，Provider 继续管理 Space。扩展不可用时，新会话使用 Ego 原生通道。
- Mearl 3.1.4 至 3.1.11 可继续用 `browser_manage launch` 和返回的浏览器 ID 操作 Space。新版会话入口需要 Mearl 3.2，配合新版扩展才能选用扩展页面通道。
- 在 Mearl 3.1 中，已启用的 Ego 扩展可能单独出现在浏览器列表中。需要继续沿用仅通过 Provider 操作 Space 的行为时，可先升级 Mearl，或暂时保留 Provider 0.1.5。
- 从 Mearl 3.1 升级后，如果正在运行的 Ego Lite 未出现在 `browser_list`，先结束现有 Provider 会话，再重启运行 Mearl 的电脑并重新打开 Ego Lite。这样可以启动新版 Provider 控制进程。
