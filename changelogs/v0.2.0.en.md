### Browser discovery and task sessions

- Mearl 3.2 discovers a running Ego Lite browser through `browser_list`. Use `session_manage new` to create a Space, or pass `providerOptions.spaceId` to attach an existing Agent Space.
- Reuse one session ID for page actions, handoff, resume and completion. A Mearl extension that matches the task page handles supported page actions while the Provider manages the Space. New sessions use Ego's native connection when the extension is unavailable.
- Mearl 3.1.4 through 3.1.11 can continue using `browser_manage launch` and the returned browser ID. The session workflow requires Mearl 3.2. Using the extension for page actions also requires the matching extension version.
- On Mearl 3.1, an enabled Ego extension may appear separately in the browser list. For the previous Provider-only Space workflow, upgrade Mearl first or keep Provider 0.1.5 until ready.
- If a running Ego Lite browser is missing from `browser_list` after upgrading from Mearl 3.1, finish existing Provider sessions, restart the machine running Mearl, and reopen Ego Lite to start the updated Provider control process.
