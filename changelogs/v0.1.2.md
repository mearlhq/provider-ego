### 启动与恢复

- macOS 在 PATH 之外检查 Ego 的标准用户安装入口，解决桌面宿主找不到 `ego-browser` 的问题。
- Windows 使用原生 `ego-browser.exe`，依次检查 PATH 和用户目录下的 `.local\share\ego\active_version_dir`，无需 shell 包装。
- 握手前启动失败后，可在安装完成后重新发起请求，不必重启 Provider。已派发请求的断线或超时仍不自动重放。

macOS 已验证真实连接、页面操作、设备模拟及任务控制；Windows 已覆盖路径解析测试，尚未真机验证。Linux 尚不在 Ego Lite 官方支持的平台内。

需要 Mearl 3.0.7+、Node.js 22.23.4+。升级 Mearl 后须确保浏览器宿主及独立 Provider 控制宿主均已重启，避免继续运行旧协议实现。
