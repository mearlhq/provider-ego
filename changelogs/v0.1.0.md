### 首个正式版

- 通过 Ego 原生通道管理任务 Space、页面操作、接管、交还与收尾，无需浏览器扩展或独立协作 Skill。
- 支持设备与 App 模拟、设备外壳、根 WebView 和已安装 App 宿主服务；真实授权仍由用户完成。
- 在 macOS EgoLite 中默认关闭扩展 Agent 接入，保留用户明确覆盖；空闲页面不轮询控制权。
- 页面关闭时释放对应宿主，保留结果页不受影响。

需要 Mearl 3.0.6+、Node.js 22.23.4+ 和可执行的 `ego-browser`。

```bash
npx @mearl/setup@latest provider install @mearl/provider-ego
```
